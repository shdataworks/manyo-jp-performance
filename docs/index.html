데이터 연결 상태

상단의 데이터 새로고침을 누르면 연결된 구글 시트의 AMZ JP RAW와 AMZ JP Keywords Raw를 다시 불러와 모든 메뉴에 적용합니다. 마지막 조회 시각으로 반영 여부를 확인할 수 있습니다. 전체 기간으로 보고 있었다면 새 날짜도 자동으로 포함됩니다. 직접 지정한 기간과 필터는 유지됩니다. 새로고침 결과는 현재 열린 화면에 적용되며, 페이지를 다시 열면 저장된 사본부터 표시됩니다.

계산 기준

CTR = 클릭 ÷ 노출, CPC = 광고비 ÷ 클릭, CPM = 광고비 ÷ 노출 × 1,000, VTR = 조회 ÷ 노출, ER = (좋아요+댓글+공유+저장) ÷ 노출, CVR = 구매 ÷ 클릭, ROAS = 매출 ÷ 광고비, ACOS = 광고비 ÷ 매출입니다. 분모가 0이면 ‘—’로 표시합니다.

광고비와 매출은 Google RAW에 저장된 원화 값을 그대로 사용합니다. Meta 구매·매출은 RAW의 추정값이며 별도의 고정 전환율을 다시 적용하지 않습니다. 주간은 월요일~일요일 기준입니다.

리포트 대응

Summary의 월간·주간·일간, Meta의 상품별, Amazon의 광고 유형별, 캠페인·소재·키워드 상세를 구현했습니다. Keyword 화면은 AMZ JP Keywords Raw 시트를 사용하며, 엑셀 Keywords 시트의 Keyword report와 같은 키워드별 성과 표로 확인할 수 있습니다.

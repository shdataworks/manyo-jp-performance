빈칸은 목표 미설정으로 저장됩니다. 이 브라우저에만 저장되며 다른 기기·브라우저에는 공유되지 않습니다. 브라우저 사이트 데이터를 지우면 목표도 삭제됩니다.

데이터 연결 상태

상단의 데이터 새로고침을 누르면 연결된 구글 시트의 AMZ JP RAW와 AMZ JP Keywords Raw를 다시 불러와 모든 메뉴에 적용합니다. 마지막 조회 시각으로 반영 여부를 확인할 수 있습니다. 전체 기간으로 보고 있었다면 새 날짜도 자동으로 포함됩니다. 직접 지정한 기간과 필터는 유지됩니다. 정상 조회한 데이터는 이 브라우저에도 저장됩니다. 같은 매체·월의 데이터는 새 응답으로 교체하고, 원본에서 빠진 과거 월은 보관 이력으로 유지합니다. 보관 이력의 마지막 날짜는 조회 상태에 별도로 표시됩니다. 다시 접속하면 최신 저장본을 표시한 뒤 원본을 조회하며, 연결이 지연되면 표시 중인 데이터의 마지막 날짜를 확인할 수 있습니다.

계산 기준

CTR = 클릭 ÷ 노출, CPC = 광고비 ÷ 클릭, CPM = 광고비 ÷ 노출 × 1,000, VTR = 조회 ÷ 노출, ER = (좋아요+댓글+공유+저장) ÷ 노출, CVR = 구매 ÷ 클릭, ROAS = 매출 ÷ 광고비, ACOS = 광고비 ÷ 매출입니다. 분모가 0이면 ‘—’로 표시합니다.

광고비와 Amazon 매출은 Google RAW의 값을 사용합니다. Meta 구매수는 Shop now 클릭 × 5%, 매출은 추정 구매수 × 2,700엔 × 8.8563원/엔으로 계산하고 행별 원 단위로 반올림합니다. 이 환율은 기존 원본의 적용값이며 실시간 환율이 아닙니다. 주간은 월요일~일요일 기준입니다.

리포트 대응

Summary의 월간·주간·일간, Meta의 상품별, Amazon의 광고 유형별, 캠페인·소재·키워드 상세를 구현했습니다. Keyword 화면은 AMZ JP Keywords Raw 시트를 사용하며, 엑셀 Keywords 시트의 Keyword report와 같은 키워드별 성과 표로 확인할 수 있습니다.
